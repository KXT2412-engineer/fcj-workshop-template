### 13-Week Internship Journey Summary

After the internship and efforts at First Cloud Journey, I have achieved significant milestones in both mindset and technical skills:

- **Mastering the AWS Ecosystem:** Hands-on setup and secure configuration of various core cloud services including IAM, VPC, EC2, S3, RDS, CloudWatch, and SNS/SES, moving beyond purely coding on Localhost.
- **Robust Backend Development:** Built an API system using C#/.NET Core with a clear layered architecture (API, BLL, DAL). Methodically managed the Database through Entity Framework Core (Code-First) and handled features ranging from basic CRUD to advanced functionalities.
- **System Operation & Monitoring:** Successfully integrated Amazon CloudWatch combined with Serilog to track and log all application activities, ensuring rigorous monitoring capabilities in a real-world environment.
- **Automation & Logic Optimization:** Developed complex algorithms such as the automatic wallet renewal mechanism (Auto-renew) and Background Jobs processing system, ensuring smooth application operations across financial cycles without bottlenecks.
- **True Software Engineer Mindset:** Upgraded awareness of network and resource security (Security Groups, IAM Least Privilege), became familiar with Cloud-Native infrastructure operation mindset, and prepared for a professional working environment.
